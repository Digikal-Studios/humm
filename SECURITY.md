# Security Policy

## Supported versions

Security fixes are applied on the default branch (`main`). There is no
long-term support branch yet.

## Reporting a vulnerability

Please **do not** open a public GitHub issue for security problems.

Use [GitHub Security Advisories](https://github.com/Digikal-Studios/humm/security/advisories/new)
for this repository (Report a vulnerability). That keeps the report private
until a fix is ready.

Include enough detail to reproduce the issue (affected version or commit,
platform, steps, and impact). We will acknowledge reports and work on a fix
when we can.
